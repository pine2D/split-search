# 商店与 README 图片模板（定稿方向 d1「纸白 · 精排」）

一句话：暖白纸底、近黑字、一抹松针绿；页头一栏左对齐，真实截图占画面主体，标注只用 1px 细线和一行小字。

2026-10-24 从三个备选方向里选定 d1（备选和当时的渲染图留在 `assets/proposals/`，对比见 `assets/proposals/compare.png`），这一目录就是原来的 `assets/templates-d1-paper/`。渲染命令（在仓库根目录运行）：

```bash
node scripts/store/render-assets.mjs            # 全部模板，输出到 assets/store/、assets/readme/
node scripts/store/render-assets.mjs --list     # 只列模板、尺寸和输出路径
```

图标：纸白底板上的图标用 `.plate > .icon`，由 `base.css` 用绝对定位 + translate 居中。`.icon` 故意比底板大（图标母版四周有透明边），溢出的 grid / flex 子项用 `place-items:center` 不会居中，会偏向右下（d1 提案图里小宣传图偏了 4px，顶部宣传图偏了 1px），所以别改回 grid 居中。

## 字体与字号

只用一个字族：Sarasa UI SC（更纱黑体 UI，拉丁部分是 Inter，中文部分是思源黑体），代码用 Sarasa Fixed SC。字体按字族名经 fontconfig 解析（`fc-match "Sarasa UI SC"`），不写文件路径，也不从网络加载。

字体栈只写 `"Sarasa UI SC", sans-serif`，不再列 Noto 等后备字体：本机没有 Noto Sans CJK SC，换字体会改变字宽和折行，所以不让它悄悄退回。每个模板都加载 `fonts.js`，它在截图前（`window.beforeCapture`）比较字宽，确认 Sarasa UI SC 和 Sarasa Fixed SC 都在；缺任何一个，这张图就报“缺少字体”渲染失败，`render-assets.mjs` 以非零码退出。换机器渲染前先装更纱黑体，用 `fc-match "Sarasa UI SC"` 确认。

- 截图 2、3 的结果分屏只显示到百度窗格的 logo 和搜索框，百度一侧的正文被块的右缘截掉；要两侧都完整，就得把整窗缩到约 0.29，字会读不清。

## 多语言（i18n/）

画面里所有要翻译的文字都在 `i18n/<locale>.json`（`zh_CN` 是源语言，另有 `en`、`zh_TW`、`es`，与扩展 v0.2 的 `_locales` 同名）。模板里只留不翻译的东西：产品名 Split Search、引擎名、网址、步骤编号。

- 文件格式：平铺的 `{ "键": "文字" }`，键按图分组（`small.*`、`marquee.*`、`hero.*`、`how.*`、`shot1.*`…`shot5.*`）。所有语言的键集合必须与 `zh_CN.json` 完全相同，`test/store-i18n.test.js` 会检查，模板里用到的 `data-t` 键也必须都在 `zh_CN.json` 里。
- 模板写法：`<h1 data-t="shot1.title"></h1>`，渲染时整段换成文字（纯文本，不解析 HTML）。要和不翻译的部分并排时，把 `data-t` 放在单独的 `<span>` 上，例如 `<h2><b>1</b><span data-t="how.step1"></span></h2>`。
- 换行：值里写 `\n`，渲染时变成 `<br>`（例如 `marquee.title` 的 `"一次搜索，\n两个引擎对比"`）。不要在值里写 `<br>`，会原样显示。
- 字体：`base.css` 按 `<html lang>` 选字族，zh-CN / en / es 用 Sarasa UI SC，zh-TW 用 Sarasa UI TC；`fonts.js` 检查当前语言要用的字族。
- 微调：需要按语言改字号、字距、折行时，建 `i18n/<locale>.css`（有就自动加载），规则用 `:lang()` 限定，例如 `:root:lang(es) .head h1 { font-size: 36px; }`。
- 截图：`assets/raw/<locale>/` 里有同名截图时，这个语言改用它（目前只有 `en`，宣传截图暂时只做英文）。英文截图里选区、拖拽落点、裁切下沿和 `_ss` 网址与中文版不同，模板在对应元素上写 `data-crop-en`、`data-box-en`、`data-d-en`（svg.ann 的路径）、`data-text-en`（文字），`crop.js` 按 `<html data-raw>` 选用，没有就用默认值。
- 检查：渲染时缺键直接报错（不会退回中文）；文字超出所在块、定位容器或画布也报错；会自动折行的元素带 `data-lines="n"`，译文折成超过 n 行同样报错。命令以非零码退出。

```bash
node scripts/store/render-assets.mjs --locale zh_CN   # 默认；store → assets/store/zh_CN/，README → assets/readme/
node scripts/store/render-assets.mjs --locale en      # store → assets/store/en/，README → assets/readme/en/
node scripts/store/render-assets.mjs --locale zh_TW
node scripts/store/render-assets.mjs --locale es
node scripts/store/render-assets.mjs --locale all     # i18n/ 里有 json 的全部语言
```

小宣传图和顶部宣传图在 CWS 不能按语言区分，但这里每种语言都会出一张，上传哪一张提交时再定（见 `docs/store/assets-spec.md`）。
