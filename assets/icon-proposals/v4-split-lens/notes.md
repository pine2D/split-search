# 方案 4：分屏镜片

思路：主体换成放大镜，镜片被一条透明竖缝分成两半，左半紫、右半橙，镜圈和手柄用品牌紫。理由：先读出“搜索”，再读出“一分为二”，概念最贴合“分屏搜索”，轮廓（圆 + 斜柄）和原生分屏按钮完全不同，不会混淆；色块面积大，16px 下也稳。风险：放大镜是搜索类图标的通用符号，若别家也用分色镜片会撞车；16px 下镜片太小放不下两个半圆加竖缝，所以 16px 版只把右半填橙、左半留空，和大尺寸略有差异；缩放到 24px（1.5 倍屏）时竖缝可能略糊。

文件：`icon.svg` 是 128×128 母版（图形在中央 96×96，四周 16px 透明留白），48 和 128 由它渲染；`icon-32.svg`、`icon-16.svg` 是按像素网格单独调整的小尺寸版本。
