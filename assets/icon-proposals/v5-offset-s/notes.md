# 方案 5：错位窗格

思路：两块窗格上下错开，左格左上角、右格右下角用大圆角，其余为小圆角，整体呈中心对称，像一个抽象的“S”（Split / Search），左格紫色渐变、右格橙色渐变。理由：保留“左右两格”的分屏语义，又有品牌字母的暗示，形状独特、适合做成长期品牌标识，在 16px 下仍是两块大色块。风险：抽象度较高，第一次见到的用户未必读出“S”或“搜索”；错位让它更像“对话气泡”或“拼图”，需要配合名称和宣传图建立认知。

文件：`icon.svg` 是 128×128 母版（图形在中央 96×96，四周 16px 透明留白），48 和 128 由它渲染；`icon-32.svg`、`icon-16.svg` 是按像素网格单独调整的小尺寸版本。
