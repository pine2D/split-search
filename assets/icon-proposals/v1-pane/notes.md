# 方案 1：原生分屏线框

思路：几乎照搬 Chrome 分屏按钮的“[|]”造型，只把线条加粗、圆角放大并换成单一品牌紫（#6A5CFF）。理由：用户一眼就能联想到“分屏”，学习成本最低，16px 下用 2px 实心线框和 2px 分隔线，像素对齐，清晰度最好。风险：和原生分屏按钮太像，两者并排出现在工具栏时容易混淆、显得像仿冒；也没有任何“搜索”含义，在应用店里辨识度最弱。

文件：`icon.svg` 是 128×128 母版（图形在中央 96×96，四周 16px 透明留白），48 和 128 由它渲染；`icon-32.svg`、`icon-16.svg` 是按像素网格单独调整的小尺寸版本。
