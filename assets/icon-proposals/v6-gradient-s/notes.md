# 方案 6：渐变字标

思路：做成应用图标式的圆角方底板，填紫—品红—橙对角渐变，底板右半叠一层暗色，形成一条竖直的“分屏”色缝；中间是完整的白色几何字母“S”（Split / Search）。理由：最大胆、最像正式产品的品牌标识，在应用店列表和扩展管理页最抢眼；白字落在实心底板上，浅色、深色工具栏都清楚。曾试过用竖缝直接切开 S，结果像美元符号“$”，所以改为让底板分色、字母保持完整。风险：满版底板在工具栏里比其他图标“重”，和 Chrome 简洁的线性图标风格反差大；字母 S 本身不说明功能，需要靠名称；16px 下渐变和分色缝被压得很弱，基本只剩“彩色方块 + S”。

文件：`icon.svg` 是 128×128 母版（图形在中央 96×96，四周 16px 透明留白），48 和 128 由它渲染；`icon-32.svg`、`icon-16.svg` 是按像素网格单独调整的小尺寸版本。
