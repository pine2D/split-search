# 方案 3：双色分屏

思路：把分屏拆成两块实心窗格，左紫（#6A5CFF）右橙（#F26B3A），大图里每格加一条白色搜索框和两行结果线。理由：实心色块在 16px 下最醒目，在浅色和深色工具栏上都有足够面积；双色直接表达“两个引擎左右对比”，同时和原生分屏按钮明显区分。风险：配色要避开 Google 四色和 Bing 青绿，橙色仍可能让人联想到某些品牌；两块方色块偏通用，需要靠配色建立辨识度；橙色在浅色工具栏上对比度偏低（约 2.7），主要靠紫色那半边撑住。

文件：`icon.svg` 是 128×128 母版（图形在中央 96×96，四周 16px 透明留白），48 和 128 由它渲染；`icon-32.svg`、`icon-16.svg` 是按像素网格单独调整的小尺寸版本。
