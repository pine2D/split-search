# 方案 2：分屏 + 放大镜

思路：保留分屏线框，在右下角叠一个放大镜，线框在放大镜周围留出透明间隙。理由：同时表达“分屏”和“搜索”两层含义，仍然沿用用户熟悉的分屏符号，比方案 1 多了产品语义。风险：16px 下放大镜只有约 6px、镜片内孔 2px，线框也只能改成 1px 细线才放得下，在 1x 屏幕上接近辨识下限；元素多、显得略挤；“窗口 + 放大镜”在搜索类扩展里很常见，独特性一般。

文件：`icon.svg` 是 128×128 母版（图形在中央 96×96，四周 16px 透明留白），48 和 128 由它渲染；`icon-32.svg`、`icon-16.svg` 是按像素网格单独调整的小尺寸版本。
