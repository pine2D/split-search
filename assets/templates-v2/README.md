# 商店图第二版（v2，2026-10-25，目前只有 en）

一句话：一句大字讲一件事，旁边只放证明这件事的那一块真实截图，放大到看得清。

起因：第一版（`../templates/`，d1）把整窗截图缩到约 0.44，标题 40px，商店轮播缩到 640×400 后功能文字和截图里的字都看不清。

## 渲染

```bash
node scripts/store/render-assets.mjs --locale en   # 商店 7 张来自本目录，README 2 张仍来自 ../templates/
```

`render-assets.mjs` 不传 `--templates` 时，在这里的 `i18n/` 有文案的语言，`asset-out` 相同的商店图改用本目录的模板（`scripts/store/template-sets.mjs`）；其他语言和 README 图不受影响。`test/store-v2.test.js` 检查文案键、截图和这条替换规则。共用 `../templates/fonts.js`（字体检查）和 `../templates/crop.js`（按原图像素坐标裁切）。

## 版式

两种版式交替（1 上下、2 左右、3 上下、4 左右、5 上下）：

- 上下（`body.top.one`，截图 1、3、5，三张坐标相同）：眉题 y 48–80，标题 80/82px 一行 98–180，副标题 30px 196–236，卡片从 y 284、x 72 起，截图卡片向右、向下出血；截图 5 的白卡高 340（284–624）。标题一行放不下的语言去掉 `.one` 用两行版（标题 98–262，副标题 276–316，卡片从 352 起）。
- 左右（截图 2、4）：左栏 x=72 起、宽 520，眉题 + 标题 + 副标题整块垂直居中；右侧窗口（`.win`）也以 y=400 为中心、向右出血。
- 眉题：图标 + SPLIT SEARCH，22px、字距 .16em、松针绿。卡片：白底、14–16px 圆角、柔和投影；要留白边时在 `.crop` 外包 `.win`（`--win-p` 设内边距）。
- 截图 3：正文选区不加框（离相邻字母只有 4–5px，框线会压字），保留原生蓝色高亮，虚线从选区右上方的实心圆点起，只走空白（两段正文之间的空行、正文和信息框之间的缝），标签栏上的拖拽影像加框；卡片顶上补 10px 标签栏同色。
- 截图 4：只放前四个引擎。Perplexity 在设置页带“Better on the right”提示，裁掉提示会说过头，带上提示又会在画布右缘截断。DuckDuckGo、Bing 两行右侧多一行“不能隐藏”的说明（在画布外），整块裁切会在它们的复选框下面多出一行空白，所以按行分三段裁、上下紧接；顶部宣传图的 02 卡片同样分两段。
- 截图 5（隐私）没有可裁的界面：一张白卡分三栏，三条事实与商店详情 PRIVACY 段一致。
- 小宣传图：图标 124px + 产品名两行 60px + 一行 29px 标签（缩到 220×140 时约 15px），可见内容左右边距都 ≥24px。
- 顶部宣传图：左栏大标题 96px + 一行说明 + 一行 22px 松针绿小字（标签栏拖拽）；右栏两张等宽（576）、左右缘对齐的卡片，整组垂直居中：01 地址栏、02 默认左右两个引擎。标签栏拖拽没有能放大看清的小裁切，交给左栏那行字。
