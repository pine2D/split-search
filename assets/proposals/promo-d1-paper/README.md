# 宣传图方向 d1-paper：纸白 · 精排

一句话：暖白纸底、近黑字、一抹松针绿，页头按分屏的左右两栏排，让版式本身就在说“一分为二”。

模板在 `assets/templates-d1-paper/`，渲染命令（在仓库根目录运行）：

```bash
node scripts/store/render-assets.mjs --templates assets/templates-d1-paper --out assets/proposals/promo-d1-paper
```

| `#507665` | 唯一强调色（图标左格同色）：标注细框、箭头、截图小标签底、小宣传图左格 | 0.532 / 0.051 | 4.6 : 1（白字 5.1 : 1） |

截图外框：1px `rgba(29,35,32,.13)` 描边，加一层很淡的投影（`0 14px 32px -18px`），只让截图从纸面上浮起一点。

没有渐变、发光和紫色、橙色；最大的彩色面积是小宣传图左格的松针绿（C 0.051）。图标右格的暖雾灰 `#8C8881` 只出现在图标里。

## 版式

- 商店截图（1280×800）：左右边距 48，截图宽 1184，所以分屏中缝落在画布中线 640。页头也按中线分两栏：左栏放标题（≤ 12 字），右栏从 664 开始放副标题和脚注，两栏基线对齐，正好压在下面的左右两个窗格上方。
- 截图都是真实画面，向下出血；叠在上面的局部（地址栏下拉、松手后、添加到 Chrome）只加一层更深的投影，不加白边。
- 标注只用 2px 松针绿细框，向外让 3px；箭头是 3px 细线，空心箭头。截图小标签（“输入”“回车后”“松手后”）是贴在截图上沿的松针绿小标签。
- 小宣传图（440×280）像图标一样分两格：左格松针绿放图标，右格纸白放产品名和“双引擎分屏搜索”。缩到 220×140 时图标、名字和标签都能认出。
- 顶部宣传图（1400×560）：左栏品牌、两行标题、细线下一行说明；右侧真实分屏截图向右、向下出血。
- README 首图：页头左栏品牌、右栏一句话；截图完整带框，下方标出“左 DuckDuckGo / 右 Bing”，不再用白色渐隐。
- README 原理图：三栏，每栏顶上一条 1px 墨线，编号是松针绿数字（这里确实是先后顺序）；降级说明改成底部通栏一行。

## 待定

- CWS 对小宣传图和顶部宣传图的建议是“用饱和色，少用大面积白色和浅灰”。小宣传图已用松针绿左格给出清楚的色边；顶部宣传图仍是纸白底，被选作首页推荐时可能显得偏淡。要更稳妥，可以把顶部宣传图左栏也铺成松针绿。
- 截图里设置页标签仍是 Chrome 生成的灰底“S”图标（`assets/raw/` 拍摄时还没有正式图标），上架前要重拍，见 `docs/store/assets-spec.md` 第 1 节。
- 字体来自 Windows 字体目录（`/mnt/c/Windows/Fonts` 里的更纱黑体）。换一台没有更纱黑体的机器渲染会退回 Noto Sans CJK SC，字宽略有不同，需要再检查一遍折行。
