# 宣传图方向 d3-split：分屏 · 叙事

一句话：画布本身就是一次分屏，左格松针绿、右格暖雾灰，中间一条 2px 白缝，和图标两格之间的缝一样；“一次搜索，两个引擎”由版面结构说出来，不靠装饰。

模板在 `assets/templates-d3-split/`，渲染命令：

```bash
node scripts/store/render-assets.mjs --templates assets/templates-d3-split --out assets/proposals/promo-d3-split
```

## 版面规则

- 缝永远在画布正中（1280 宽在 x=639–641，1400 宽在 x=699–701，README 在 CSS x=439–441）。
- 带分屏的真实截图按 0.5 倍（README 按 808/2400）放置，让浏览器自己的窗格分界线正好接在画布的缝上（截图 1、2、marquee、README 首图）。
- 左格放“是什么”（标题、产品名），右格放“怎么回事”（一行说明），两边都从缝外 40px 起排；标题和说明行的汉字字形下沿都在 y≈96。页头只有标题和一行说明，没有第三层文字。
- 窗口截图顶边只用两档：y=152（截图 1、3）和 y=232（截图 4、5）；截图 2 上方多一个下拉框，整窗在 y=288。
- 截图 4、5 和原理图下半部分：一格一件事，左右两格各放一张截图，两边同一比例、等宽。
- 要表示“分屏”的小图（截图 3 的松手后卡片、截图 5 左卡、原理图第 3 步）不再整窗缩小，而是两个窗格各取左上一段、同一比例并排，中间留 6px，比例 ≥0.45（原理图为 0.345，和旁边的普通结果页相同）。
- 标注只用 2px 松针绿细线框、细虚线箭头和小号深色文字；不用胶囊色块、不用光晕。
- “百度为自行添加的引擎”（assets-spec 第 7 条）：截图 2 是贴在右下角的小白条，截图 3 并进“松手后”卡片的标注。

## 待定

- 截图 4 两张卡片是 0.52 倍（设置页正文约 11.5px）。设置页卡片内容本身约 1060 原图像素宽，按 40px 网格每格只有 560px，放不到 0.6 倍；要更大只能改成一格一张图，或重拍时把设置页窗口调窄。
- 截图 4 右卡里设置页自己的浅蓝“默认组合”面板和蓝色“新增引擎”按钮是全套最大的饱和色块；设置页改用松针绿主题后重拍即可消除。
- 截图 3 的虚线箭头从选区出发时仍穿过两行正文，之后沿标题右侧空白走到落点，不再经过右侧信息框。
- 浅色画布上的白缝对比只有约 1.2:1，是有意做得很轻；如果要更明显，可以改成 `--ink-2` 细线。
- CWS 对小宣传图的建议是“用饱和色、少用浅灰”。这里按用户要求用低饱和中间色；缩到 220×140 时图标、产品名和标签语都清楚，缩到 146 宽时标签语只剩约 9px。
