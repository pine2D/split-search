# 宣传图方向 d3-split：分屏 · 叙事

一句话：画布本身就是一次分屏，左格松针绿、右格暖雾灰，中间一条 2px 白缝，和图标两格之间的缝一样；“一次搜索，两个引擎”由版面结构说出来，不靠装饰。

模板在 `assets/templates-d3-split/`，渲染命令：

```bash
node scripts/store/render-assets.mjs --templates assets/templates-d3-split --out assets/proposals/promo-d3-split
```

## 版面规则

- 缝永远在画布正中（1280 宽在 x=639–641，1400 宽在 x=699–701，README 在 CSS x=439–441）。
- 带分屏的真实截图按 0.5 倍（README 按 808/2400）放置，让浏览器自己的窗格分界线正好接在画布的缝上（截图 1、2、marquee、README 首图）。
- 左格放“是什么”（标题、产品名），右格放“怎么回事”（一行说明），两边都从缝外 40px 起排，末行基线对齐。
- 截图 4、5 和原理图下半部分：一格一件事，左右两格各放一张截图和一行标注。
- 标注只用 2px 松针绿细线框、细虚线箭头和小号深色文字；不用胶囊色块、不用光晕。

## 待定

- 截图 4 右图从“只放默认组合、放大 0.67”改成与左图同为 0.5 倍（多带了“其他组合”和设置步骤前四步），设置页正文约 11–12px，比原方案小。
- 截图 5 左图放大到约 0.36 倍后，右侧 Bing 窗格只露出左边一条，靠分界线认出是分屏。
- 浅色画布上的白缝对比只有约 1.2:1，是有意做得很轻；如果要更明显，可以改成 `--ink-2` 细线。
- CWS 对小宣传图的建议是“用饱和色、少用浅灰”。这里按用户要求用低饱和中间色，缩到 220×140 时仍能认出图标、产品名和标签语。
