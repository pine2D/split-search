# 宣传图方向 d2-graphite（石墨 · 专业）

一句话：深石墨底上只放一行标题和一张清楚的真实截图，用一行等宽字的“键入 ↵”表示“输入一次就够”，整体像一件专业开发工具：快、准、不吵。

模板：`assets/templates-d2-graphite/`（自带 `base.css`、`crop.js`）。重渲：

```bash
node scripts/store/render-assets.mjs --templates assets/templates-d2-graphite --out assets/proposals/promo-d2-graphite
```

## 配色

大面积颜色 OKLCH chroma 都 ≤ 0.013；只有图标本身和一个强调色带一点松针绿。不用紫色、橙色、渐变、发光和大投影。

| Token | Hex | OKLCH（L / C） | 用途 |
|---|---|---|---|
| `--ground` | `#1B2120` | 0.24 / 0.009 | 全部画面的底色，石墨略带绿 |
| `--raised` | `#242B29` | 0.28 / 0.010 | 键入框、触发网址框、标签底 |
| `--rule` | `#343D3A` | 0.35 / 0.013 | 键入框描边、分隔线 |
| `--frame` | `rgba(232,238,234,.26)` | — | 截图外 1px 细框 |
| `--ink` | `#ECEEEA` | 0.95 / 0.006 | 标题、主文字（对底色 14:1） |
| `--muted` | `#9BA49F` | 0.71 / 0.012 | 副标题、说明（6.4:1） |
| `--dim` | `#818B87` | 0.62 / 0.013 | 角落小注（4.6:1） |
| `--accent` | `#9FBDAF` | 0.77 / 0.038 | 唯一强调色（浅松针）：光标、↵、`_ss` 标记、步骤编号（8.1:1） |
| 标注线 | `#3F6656` | 0.48 / 0.052 | 画在白色网页上的标注框和虚线箭头（对白 6.5:1） |
| `--pine` / `--fog` | `#507665` / `#8C8881` | — | 只出现在图标里，不另作装饰 |

图标直接放在石墨底上，不加白色底板。

## 字体与字号

- 正文与标题：Noto Sans SC（本机字体，700 / 500 / 400）。
- 等宽：Sarasa Fixed SC，只用于“真的会被输入或复制的东西”：键入的查询词、触发网址、步骤编号。

| 位置 | 字号 / 字重 |
|---|---|
| 小宣传图产品名 / 标语 | 44 / 700，23 / 500（字距 .06em） |
| 顶部宣传图标题 / 品牌行 / 键入 | 60 / 700，24 / 500，24 等宽 |
| 商店截图标题 / 副标题 / 小注 | 46 / 700，21 / 400，15 / 400 |
| README 首图标题 / 键入（CSS 像素，2 倍输出） | 24 / 700，15 等宽 |
| 原理图步骤 / 说明 / 网址 | 15 / 700，11.5 / 400，12.5 等宽 |

网格：商店截图左右 64px，标题左对齐，截图与标题同一左边、向下出血；顶部宣传图 72px 边距，截图顶边对齐品牌行；README 40px（原理图 32px）。

## 待定

- 规格（`docs/store/assets-spec.md`）引用 CWS 建议“小宣传图用饱和色”。这套按用户要求走低饱和；深色底在浅色商店页上仍然醒目，也没有大面积白色或浅灰。
- 图标左格松针绿在石墨底上对比不高（L 0.53 对 0.24），缩小后靠白色横条和暖雾灰右格辨认。
- 截图 5 左图沿用原裁切，右侧 Bing 窗格只露出左半。
- 字体依赖本机的 Noto Sans SC 和 Sarasa Fixed SC；别的机器缺字体时会回退，需要重新检查。
