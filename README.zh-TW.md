# Split Search

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [Español](README.es.md)

一次搜尋，在 Chrome 分割畫面中左右並排開啟兩個搜尋引擎的結果。

![Chrome 分割畫面中，左側 DuckDuckGo、右側 Bing 同時顯示「rust programming」的搜尋結果](assets/readme/zh_TW/hero.png)

## 功能

- 在網址列搜尋或把文字拖到分頁列，並排對照兩個搜尋引擎；可新增自訂引擎，也能設定多組搭配與各自的搜尋捷徑
- 選取網頁文字或對圖片按右鍵，保留原網頁，在旁邊分割查詢或以圖搜圖
- 在已設定引擎的搜尋結果頁點選工具列圖示，就能在右側加開第二個引擎；分割畫面中點選圖示或按快速鍵可隨時切換右側引擎，不必重新輸入
- 搜尋字詞含特定關鍵字或日文、韓文等文字時，自動切換右側引擎（例如搜尋含「影片」時換成 YouTube，並可一併移除該字詞）

## 安裝

需要 Chrome 155 以上版本。

**[從 Chrome 線上應用程式商店安裝](https://chromewebstore.google.com/detail/Split%20Search/ebefmgpipceocigodihbbbhdiagmjdak)**

手動安裝：

1. 在 [Releases](https://github.com/pine2D/split-search/releases/latest) 下載 `split-search-<版本>.zip` 並解壓縮。
2. 前往 `chrome://extensions`，開啟右上角「開發人員模式」，點選「載入未封裝項目」，選擇解壓縮後的資料夾。
3. 安裝後會自動開啟設定頁。

更新時直接解壓縮覆蓋原資料夾，再點選擴充功能卡片上的「重新載入」。若換了資料夾，Chrome 會視為新的擴充功能，原有設定不會保留。

## 快速上手

直接在搜尋結果頁使用：開啟 Google、Bing 等搜尋結果頁，點選工具列上的 Split Search 再選一個引擎，就能在右側並排對照，原有的預設搜尋照常保留；也可在設定頁「開始使用」授權左側引擎後，點選「試試範例搜尋」。

若想從網址列直接分割搜尋，可在 Chrome 新增一筆網站搜尋：

1. 在設定頁「搜尋組合」選好左右引擎（若提示未授權，請先授權左側引擎），切到「新增到 Chrome」複製組合網址，點選「開啟 Chrome 搜尋設定」。
2. 在「網站搜尋」旁點選「新增」，填好名稱與搜尋捷徑（如 `gb`），把網址貼到「以 %s 取代查詢的網址」欄，再點選「新增」。
3. 在網址列輸入搜尋捷徑，按 Tab 後輸入關鍵字就能分割搜尋。若想直接輸入關鍵字或拖曳文字到分頁列時也開啟分割畫面，可在該項目 ⋮ 選單中選取「設為預設」（作為預設搜尋引擎時，網址列不會顯示搜尋建議）。

## 補充說明

- 可在「搜尋組合」開啟「關閉一側時，同時關閉另一側」（預設關閉），只對本次瀏覽階段由本擴充功能開啟的搜尋分割畫面有效，點選連結換頁後仍有效；右鍵查詢與窄視窗相鄰分頁不會一起關閉。取消分割畫面後立即關閉分頁時，另一側偶爾仍可能一併關閉。
- 視窗較窄（寬度不足 960 像素）時預設改用相鄰分頁：搜尋時右側結果會在背景開啟，右鍵查詢則直接切到查詢分頁。
- 在無痕視窗、未啟用本擴充功能的其他裝置或左側引擎尚未授權時，組合網址會直接開啟一般的左側引擎搜尋，不會出錯。

## 隱私

搜尋字詞、選取的文字與圖片網址只會傳送給你選擇的搜尋引擎，絕不傳給開發者或其他第三方。本擴充功能沒有伺服器，也不含統計分析與廣告：建立分割畫面時僅在本機讀取搜尋網址與目前分頁網址，不儲存這些網址；僅在你點選本擴充功能的右鍵選單時讀取選取的文字或圖片網址；目前的查詢紀錄僅暫存於瀏覽器記憶體，關閉瀏覽器即清除。詳見[隱私權政策](https://pine2d.github.io/split-search/privacy)（英文）或[簡體中文版](https://pine2d.github.io/split-search/privacy.zh-CN.html)。
