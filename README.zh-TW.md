# Split Search

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [Español](README.es.md)

在網址列搜尋，或把文字拖曳到分頁列，Split Search 會用 Chrome 分割畫面左右開啟兩個搜尋引擎的結果，方便對照。

![Chrome 分割畫面中，左側 DuckDuckGo、右側 Bing 同時顯示「rust programming」的搜尋結果](assets/readme/zh_TW/hero.png)

## 功能

- 網址列搜尋、把文字拖曳到分頁列都能左右對照；引擎可以自選、自行新增，也能設定多組，各用一個搜尋捷徑
- 對選取的文字或圖片按右鍵，就能在目前網頁旁邊查詢或以圖搜圖
- 點選工具列按鈕，就能把右側換成其他引擎，不必重新搜尋
- 右側引擎可以依關鍵字自動切換，例如搜尋內容有「影片」時改用 YouTube

## 安裝

需要 Chrome 155 以上版本。

**[從 Chrome 線上應用程式商店安裝](https://chromewebstore.google.com/detail/Split%20Search/ebefmgpipceocigodihbbbhdiagmjdak)**

手動安裝：

1. 在 [Releases](https://github.com/pine2D/split-search/releases/latest) 下載 `split-search-<版本>.zip` 並解壓縮。
2. 前往 `chrome://extensions`，開啟右上角的「開發人員模式」，點選「載入未封裝項目」，選擇解壓縮後的資料夾。
3. 安裝完成後會自動開啟設定頁。

更新時把新版本解壓縮到同一個資料夾，再點選擴充功能卡片上的「重新載入」。換了資料夾會被視為另一個擴充功能，原本的設定不會帶過去。

## 設定

先開啟 Google、Bing 或其他已加入引擎的搜尋結果頁，點選工具列上的 Split Search，再選一個引擎，就能對照結果。平常的預設搜尋引擎可以照用。也可以在設定頁的「開始使用」中允許存取左側引擎，再點選「試搜範例」。

若要從網址列使用，請在 Chrome 新增一筆網站搜尋。

1. 在「搜尋組合」選好左右引擎，再到「新增到 Chrome」。依提示允許存取左側引擎，複製組合網址，再點選「開啟 Chrome 搜尋設定」。
2. 在「網站搜尋」旁點選「新增」。填好名稱和搜尋捷徑（例如 `gb`），在「以 %s 取代查詢的網址」貼上剛複製的網址，再點選「新增」。
3. 在網址列輸入搜尋捷徑，按 Tab，再輸入關鍵字。若要讓一般搜尋和拖曳到分頁列的文字也使用這個組合，可在該項目的 ⋮ 選單中選取「設為預設」。設為預設後，網址列就不會再顯示原搜尋引擎的搜尋建議。

## 注意事項

- 可以在「搜尋組合」開啟「關閉一側時，同時關閉另一側」（預設關閉）。僅適用於本擴充功能建立的搜尋分割畫面，前往其他網頁後仍會連動；右鍵查詢和窄視窗中的相鄰分頁不受影響。取消分割畫面後立即關閉分頁，另一側仍可能一起關閉。
- 視窗較窄時，預設會以相鄰分頁顯示結果。從網址列搜尋或透過工具列新增第二個引擎時，第二個結果會在背景開啟。按右鍵查詢文字或圖片時，會切換到結果分頁。
- 在無痕視窗或其他裝置上，就只是一般搜尋。

## 隱私

你查詢的內容只會傳送給你選擇的搜尋引擎，不會傳送給開發者或其他第三方。擴充功能沒有伺服器，也不含統計分析和廣告。擴充功能會在本機讀取搜尋網址和目前分頁的網址來開啟分割畫面，這些網址都不會儲存；只有在你使用它的右鍵選單時，才會讀取選取的文字或圖片網址。查詢內容只暫存在瀏覽器記憶體中，關閉瀏覽器就會清除。詳情請參閱[隱私權政策](https://pine2d.github.io/split-search/privacy)（英文）。
