Split Search 设置

在地址栏搜索或把文字拖到标签栏，一次用两个搜索引擎打开 Chrome 原生分屏。

默认组合

左侧只能选“可作左侧”的引擎。改了默认组合后，要把新的触发网址重新添加到 Chrome 并设为默认，旧的那条才会被替换。

添加到 Chrome

设置步骤

  1. 打开 Chrome 的搜索引擎设置。这个地址不能从网页里直接打开，请复制后粘贴到地址栏： chrome://settings/searchEngines
  2. 在“网站搜索”一栏点“添加”。
  3. 名称随意（例如“Kagi ｜ Google”）；快捷字词自定（例如 kg）；网址粘贴上面复制的触发网址。保存。
  4. 默认组合：在刚添加的条目右侧 ⋮ 菜单里选“设为默认”。其他组合不用设为默认，在地址栏输入“快捷字词 + 空格 + 关键词”即可。
  5. 确认左侧引擎已授权（引擎列表里显示“已授权”）。

注意事项

  • 以下情况触发网址会降级为一次普通的左侧引擎搜索，不分屏：同步了这套搜索设置的其他电脑和手机、无痕窗口、扩展被停用、撤销了授权、引擎网站自己的 Service Worker 接管了导航。
  • 自己添加的网站搜索没有联想网址，设为默认后地址栏不再有搜索联想。
  • 右键菜单里的“在 X 中搜索”同样会走触发网址，同样会分屏。
  • Chrome 的搜索引擎设置会同步到你的所有设备，但授权不会同步：每台设备都要在这个页面单独授权。
  • 修改某个引擎的网址后，以它为左侧的网站搜索网址需要重新复制；删除或隐藏引擎前，请先删掉 Chrome 里以它为左侧的网站搜索。
