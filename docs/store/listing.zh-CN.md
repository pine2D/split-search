## 详细说明

```text
Split Search 让一次搜索同时出现在两个搜索引擎里：在地址栏输入关键词，或把选中的文字拖到标签栏，Chrome 会用原生分屏（Split View）左右打开两个引擎的结果页，方便对照。

两侧都是普通的 Chrome 标签页，各网站的登录状态和设置照常生效。扩展不使用 iframe，也不修改任何网站的响应。

【主要功能】
• 地址栏搜索、拖拽文字到标签栏，以及 Chrome 自带的右键“在 X 中搜索”，都会打开分屏
• 预置 Google、Bing、DuckDuckGo、Perplexity、Kagi；也可以用网址模板（%s 代表关键词）添加其他搜索引擎，支持编辑、隐藏和排序（部分截图右侧的“百度”就是这样添加的）
• 可以为多个引擎组合分别生成触发网址，各绑定一个你自己定的快捷字词，例如“gb 关键词”用 Google ｜ Bing，“dk 关键词”用 DuckDuckGo ｜ Kagi
• 在本扩展打开的分屏里再次搜索，会就地刷新左右两侧；另一侧不是搜索引擎页面的分屏不会被改动，新结果在旁边另开一组

【三步设置】
Chrome 不允许扩展直接更改搜索引擎，所以需要你在 Chrome 设置里手动添加一次：
1. 授权：在设置页给要用的搜索引擎点“授权”。扩展只申请这些引擎网站本身的访问权限，左侧引擎必需，右侧建议授权。
2. 复制触发网址：选好左右两个引擎，复制设置页生成的触发网址。
3. 添加为网站搜索：打开 chrome://settings/searchEngines，在“网站搜索”中添加，网址粘贴触发网址，快捷字词自定。设为默认后，地址栏直接搜索、拖拽文字到标签栏和右键“在 X 中搜索”都会分屏；不设为默认时，只有输入“快捷字词 + 空格 + 关键词”才会分屏。

【在其他设备和无痕窗口中】
触发网址就是左侧引擎的真实搜索网址，只多了一个 _ss 标记参数。在扩展不生效的地方，例如同步了这套搜索设置的其他电脑和手机、无痕窗口，或扩展被停用、未授权时，它就是一次普通的左侧引擎搜索，不会出错。

【使用限制】
• 需要 Chrome 155 或更高版本（依赖原生分屏 API）
• 一次只对比两个引擎：Chrome 的一个分屏只能放两个标签
• 无痕窗口内不分屏，按普通搜索处理
• 自己添加的网站搜索没有搜索联想，设为默认后地址栏不再显示联想建议
• 授权不随 Chrome 同步，每台设备都要在设置页单独授权
• 个别引擎网站的 Service Worker 接管导航时，这次搜索会退化为普通的左侧搜索
• 改了默认组合或左侧引擎的网址后，要把新的触发网址重新添加到 Chrome
• 界面仅提供简体中文

【隐私】
重点说明：本扩展不收集任何数据。它没有服务器，不发网络请求，不含统计、广告或远程代码，不向开发者或任何第三方发送数据。为了完成搜索，它只在你的浏览器里读取你发起的那次搜索的网址（含查询词），以及分屏另一侧标签的网址（只用来比较其网站来源，不保存）；不读取浏览历史或网页内容，除设置和关闭浏览器即清除的分屏记录外不保存任何数据。查询词只从你的浏览器发往你选择的两个搜索引擎。设置保存在 chrome.storage.sync 中；只有你开启了 Chrome 同步，Chrome 才会在你的设备之间同步它。
```

措辞说明：

- “右键‘在 X 中搜索’”指 Chrome 自带的菜单项（它用默认搜索引擎，所以会走触发网址），扩展自身没有右键菜单。拖拽到标签栏同样只用默认搜索引擎，所以第 3 步写明了“不设为默认时只有快捷字词会分屏”。
- “另一侧不是搜索引擎页面的分屏不会被改动”对应 `src/lib/split-decision.js`：分屏另一侧停在任一已配置引擎的页面上时，扩展会把它当作自己的分屏就地刷新，所以不能写成“手动建的分屏一律不覆盖”。
- 不写“一键”“最好用”等评价性词语，也不提其他扩展，避免触及关键词堆砌和误导性宣传条款。
- 【隐私】段与 `privacy.md` 的重点说明和隐私政策一致：说“不收集”，同时写明本机读取了什么；不说“不处理任何数据”，因为扩展确实会在本机读取触发网址。数据使用披露不勾选任何类别（含“网页浏览记录”），这一段是对此的公开说明，不要删减。
