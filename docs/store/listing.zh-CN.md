## 详细说明

```text
在地址栏搜索，或把选中的文字拖到标签栏，Split Search 会用 Chrome 拆分视图左右打开两个搜索引擎的结果，方便对比。

【功能】
• 地址栏搜索、拖拽文字到标签栏、右键“使用X搜索‘…’”都能用
• 已经打开某个引擎的结果页时，点工具栏按钮选另一个引擎，就能和当前页组成拆分视图
• 在网页上选中文字后右键，可以在拆分视图里查这段文字，当前网页留在左边
• 在图片上右键，可以用 Google Lens 等引擎以图搜图，结果在当前网页旁边打开
• 预置 Google、Bing、DuckDuckGo、Perplexity、Kagi，也可以添加其他搜索引擎
• 引擎库收录翻译、百科、视频、地图等适合放在右侧的网站，也有 AI 助手，可以直接添加
• 可以设多组引擎，各用一个快捷字词，例如输入“gb 关键词”对比 Google 和 Bing
• 点工具栏按钮，可以把右侧换成别的引擎，不用重新搜索
• 右侧引擎可以按关键词自动换，例如搜索里有汉字时右侧用百度。点工具栏按钮能看到换的原因，也能换回原来的引擎
• 也可以按快捷键把右侧换成下一个引擎。快捷键默认未设置，在 Chrome 的“键盘快捷键”页面（chrome://extensions/shortcuts）设置
• 窗口较窄时，右侧改在旁边的后台标签页打开，这项可以关闭
• 两侧都是普通标签页，登录状态和网站设置照常

【设置】
1. 在设置页给要用的搜索引擎授权
2. 选好左右两个引擎，复制生成的网址
3. 在 Chrome 设置的“网站搜索”里添加这个网址，并设为默认选项
设置页里有逐步说明。

【须知】
• 需要 Chrome 155 或更高版本
• 在无痕式窗口、其他设备上，或扩展没有生效时，就是一次普通搜索
• 设为默认后，地址栏不再显示搜索联想
• 只有带公开网址的图片才能以图搜图，要登录才能看的图片，引擎多半拿不到

【隐私】
扩展不把数据发给开发者或其他第三方，你要查的内容只发给你选的引擎，包括你在弹窗里或用快捷键换上的引擎。扩展没有服务器，不含统计和广告。为了打开拆分视图，扩展会在本机读取这次搜索的网址，点工具栏按钮时读取当前标签页的网址，必要时读取另一侧标签页的网址，这些网址都不保存。只有你选了本扩展的右键菜单项时，扩展才读取选中的文字或那张图片的网址，不读取页面网址和页面上的其他内容。有些图片网址本身带访问凭证，发给引擎后引擎也能打开这张图。查询的内容和两侧引擎只暂存在浏览器内存里，用来在弹窗里显示和换引擎，关闭浏览器即清除。扩展不读取浏览记录。
```

字数：1082（含换行）

措辞说明：

- 右键“使用X搜索‘…’”指 Chrome 自带的菜单项，它和拖拽到标签栏都只走默认搜索引擎，所以【设置】第 3 步要求设为默认选项。本扩展自己加的两个右键菜单项（查词、以图搜图）不经过默认搜索引擎，不需要这一步，所以【设置】不写它们，设置页的“右键查询”卡片里有说明。
- 实现细节（触发网址的 `_ss` 参数、授权不随同步、Service Worker 退化等）不写进详情，留给设置页的逐步说明和内部文档（CLAUDE.md“文案”一节）。
- 不写“一键”“最好用”等评价性词语，也不提其他扩展，避免触及关键词堆砌和误导性宣传条款。
- 【隐私】段与 `privacy.md` 一致：第一句说“不发给开发者或其他第三方，你要查的内容只发给你选的引擎”，不再说“数据只留在你的设备上”（选中的文字会按用户的要求发给引擎）；同时写明本机读取了什么、内存里暂存了什么，只在用户选了菜单项时才读选区和图片网址；不说“不收集”“不处理任何数据”或“不读取网页内容”。数据使用披露勾“网页浏览记录”和“网站内容”，这一段是对此的公开说明，不要删减。
- 新功能按用户能做什么写（补成拆分视图、右键查词、以图搜图），不写 `activeTab` 等权限名和判定细节。“以图搜图”是本扩展的功能名，Chrome 的原生菜单项叫“使用 X 搜索图片”（`docs/i18n/chrome-terms.md`）。
- 键盘快捷键写成“快捷键”，网站搜索的关键字写成“快捷字词”（Chrome 术语），两者不混用。快捷键页面名照 Chrome 界面写“键盘快捷键”。
- v0.5 新增的按关键词换右侧（2026-10-27）只在【功能】加一条，按用户能做什么写（例子用“有汉字 → 百度”，与设计稿的目标 K2 一致），不写规则怎么比、只作用于默认组合等细节，不新增截图；【隐私】段不变（规则在本机判断、随同步写在 README 和隐私政策里）。已过 lieflat-less-ai-tone 和 humanizer-zh。

## 类别

- 主类别建议：**工具（Tools）**。它是通用的浏览器效率工具，用户会在这里找“搜索”类扩展。
- 备选：**功能与界面（Functionality & UI）**。如果更想强调“增强 Chrome 拆分视图”，可以选它。

## 语言

- 控制台有 4 种语言的详情：英文 `en`（默认语言）、简体中文 `zh-CN`、繁体中文 `zh-TW`、西班牙语 `es`，对应 v0.2 加入扩展包的 `_locales/en|zh_CN|zh_TW|es`。
- 设置页可切换这 4 种语言；扩展简介、工具栏按钮的提示跟随浏览器语言，不随设置页选择。
