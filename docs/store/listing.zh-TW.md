## 詳細說明

```text
一次搜尋，在 Chrome 分割畫面中左右並排開啟兩個搜尋引擎的結果。

【功能】
• 在網址列搜尋或把文字拖到分頁列，並排對照兩個搜尋引擎；可新增自訂引擎，也能設定多組搭配與各自的搜尋捷徑
• 選取網頁文字或對圖片按右鍵，保留原網頁，在旁邊分割查詢或以圖搜圖
• 在已設定引擎的搜尋結果頁點選工具列圖示，就能在右側加開第二個引擎；分割畫面中點選圖示或按快速鍵可隨時切換右側引擎，不必重新輸入
• 搜尋字詞含特定關鍵字或日文、韓文等文字時，自動切換右側引擎（例如搜尋含「影片」時換成 YouTube，並可一併移除該字詞）

【快速上手】
1. 在搜尋結果頁直接使用：在 Google、Bing 等搜尋結果頁點選工具列上的 Split Search，再選一個引擎就能在右側並排對照，原有的預設搜尋照常保留。
2. 從網址列使用：在擴充功能設定中授權左側引擎，複製組合網址，點選「開啟 Chrome 搜尋設定」並新增到「網站搜尋」。輸入搜尋捷徑、按 Tab 後輸入關鍵字就能分割搜尋；若想直接輸入關鍵字或拖曳文字時也開啟分割畫面，再選取「設為預設」。

【補充說明】
• 需要 Chrome 155 以上版本
• 作為預設搜尋引擎時，網址列不會顯示搜尋建議
• 在無痕視窗、未啟用本擴充功能的其他裝置或左側引擎尚未授權時，組合網址會直接開啟一般的左側引擎搜尋，不會出錯

【隱私】
搜尋字詞、選取的文字與圖片網址只會傳送給你選擇的搜尋引擎，絕不傳給開發者或其他第三方。本擴充功能沒有伺服器，也不含統計分析與廣告：建立分割畫面時僅在本機讀取搜尋網址與目前分頁網址，不儲存這些網址；僅在你點選本擴充功能的右鍵選單時讀取選取的文字或圖片網址；目前的查詢紀錄僅暫存於瀏覽器記憶體，關閉瀏覽器即清除。
```
