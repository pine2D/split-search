## 詳細說明

```text
在網址列搜尋，或把選取的文字拖曳到分頁列，Split Search 會用 Chrome 分割畫面左右開啟兩個搜尋引擎的結果，方便對照。

【功能】
• 網址列搜尋、把文字拖曳到分頁列、右鍵選單的「透過 X 搜尋『…』」都能使用
• 內建 Google、Bing、DuckDuckGo、Perplexity、Kagi，也可以新增其他搜尋引擎
• 引擎庫收錄翻譯、百科、影片、地圖等適合放在右側的網站，也有 AI 助理，可以直接新增
• 可以設定多組引擎，各用一個搜尋捷徑，例如輸入「gb 關鍵字」對照 Google 和 Bing
• 點選工具列按鈕，就能把右側換成其他引擎，不必重新搜尋
• 也可以按快速鍵把右側換成下一個引擎。預設沒有設定快速鍵，請到 Chrome 的「鍵盤快速鍵」頁面（chrome://extensions/shortcuts）設定
• 視窗較窄時，右側會改在旁邊的背景分頁開啟，這項設定可以關閉
• 兩側都是一般分頁，登入狀態和網站設定都不受影響

【設定】
1. 在設定頁授權要使用的搜尋引擎
2. 選好左右兩個引擎，複製產生的網址
3. 在 Chrome 設定的「網站搜尋」中新增這個網址，並設為預設
設定頁有逐步說明。

【注意事項】
• 需要 Chrome 155 以上版本
• 在無痕視窗、其他裝置上，或擴充功能沒有生效時，就只是一般搜尋
• 設為預設後，網址列不會再顯示搜尋建議

【隱私】
資料只會留在你的裝置上，不會傳送給開發者或任何第三方。擴充功能沒有伺服器，也不含統計分析和廣告。搜尋字詞只會傳送給你選擇的搜尋引擎，包括你在彈出式視窗或用快速鍵換上的引擎。為了開啟分割畫面，擴充功能會在本機讀取這次搜尋的網址，必要時也會讀取另一側分頁的網址，但不會儲存。關鍵字和兩側的引擎只暫存在瀏覽器記憶體中，用來在彈出式視窗顯示和切換右側引擎，關閉瀏覽器就會清除。擴充功能不會讀取瀏覽記錄或網頁內容。
```
