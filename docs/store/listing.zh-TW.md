## 詳細說明

```text
在網址列搜尋，或把選取的文字拖曳到分頁列，Split Search 會用 Chrome 分割畫面左右開啟兩個搜尋引擎的結果，方便對照。

【功能】
• 網址列搜尋、把文字拖曳到分頁列、右鍵選單的「透過 X 搜尋『…』」都能使用
• 內建 Google、Bing、DuckDuckGo、Perplexity、Kagi，也可以新增其他搜尋引擎
• 可以設定多組引擎，各用一個搜尋捷徑，例如輸入「gb 關鍵字」對照 Google 和 Bing
• 兩側都是一般分頁，登入狀態和網站設定都不受影響

【設定】
1. 在設定頁授權要使用的搜尋引擎
2. 選好左右兩個引擎，複製產生的網址
3. 在 Chrome 設定的「網站搜尋」中新增這個網址，並設為預設
設定頁有逐步說明。

【注意事項】
• 需要 Chrome 155 以上版本
• 在無痕視窗、其他裝置上，或擴充功能沒有生效時，就只是一般搜尋
• 設為預設後，網址列不會再顯示搜尋建議

【隱私】
不收集任何資料：沒有伺服器，也不含統計分析和廣告。搜尋字詞只會傳送給你選擇的兩個搜尋引擎。擴充功能只在本機讀取你這次搜尋的網址，以及分割畫面另一側分頁的網址，用來開啟分割畫面；不會儲存，也不會讀取瀏覽記錄或網頁內容。
```
