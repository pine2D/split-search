## 詳細說明

```text
在網址列搜尋，或把選取的文字拖曳到分頁列，Split Search 會用 Chrome 分割畫面左右開啟兩個搜尋引擎的結果，方便對照。

【功能】
• 網址列搜尋、把文字拖曳到分頁列都能左右對照；引擎可以自選、自行新增，也能設定多組，各用一個搜尋捷徑
• 對選取的文字或圖片按右鍵，就能在目前網頁旁邊查詢或以圖搜圖
• 點選工具列按鈕，就能把右側換成其他引擎，不必重新搜尋
• 右側引擎可以依關鍵字自動切換，例如搜尋內容有「影片」時改用 YouTube

【設定】
1. 在設定頁授權搜尋引擎
2. 複製設定頁產生的網址，在 Chrome 設定的「網站搜尋」中新增，並設為預設
設定頁有逐步說明。

【注意事項】
• 需要 Chrome 155 以上版本
• 設為預設後，網址列不會再顯示搜尋建議
• 在無痕視窗或其他裝置上，就只是一般搜尋

【隱私】
你查詢的內容只會傳送給你選擇的搜尋引擎，不會傳送給開發者或其他第三方。擴充功能沒有伺服器，也不含統計分析和廣告。擴充功能會在本機讀取搜尋網址和目前分頁的網址來開啟分割畫面，這些網址都不會儲存；只有在你使用它的右鍵選單時，才會讀取選取的文字或圖片網址。查詢內容只暫存在瀏覽器記憶體中，關閉瀏覽器就會清除。
```
