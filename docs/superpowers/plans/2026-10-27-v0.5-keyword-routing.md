# Split Search v0.5 按关键词换右侧 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 地址栏、拖拽触发默认组合时，go.html 在本地按设置页里的有序规则（“搜索里有这些词”“搜索里有某种文字”）换掉右侧引擎，左侧不变；弹窗写明原因并能一键换回。

**Architecture:** 纯逻辑放在新文件 `src/lib/right-rules.js`（规范化、词边界、文字判定、读时清洗、`ruleRight` 唯一入口），`mergeConfig` 多返回 `rightRules`。go.js 在展开右侧模板前调 `ruleRight`，结果经 `auto = { rule, base }` 透传到 split-actions → split-state，写进右侧记录。弹窗用 `explainRule` 本地重算原因，设置页在“默认组合”卡里加一个收起的规则区和 `#rule-dialog`。

**Tech Stack:** Chrome MV3（minimum 155），原生 ES 模块，无构建、无依赖；`node --test`；e2e 用 `scripts/e2e`（CDP 管道，Node 24）。

**Spec:** `docs/superpowers/specs/2026-10-27-v0.5-keyword-routing-design.md`（用户 2026-10-27 批准，含文末“已定”三条）。下文“设计稿 X.Y”指它的章节；计划与设计稿冲突时以设计稿为准，下面“与设计稿的出入”一节列出的除外。
