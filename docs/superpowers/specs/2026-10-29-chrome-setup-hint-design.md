# 默认搜索设置核对提示

用户已同意在现有权限范围内完善核对提示，并要求做好 UI/UX。此改动服务于在扩展中选择组合、随后到 Chrome 设置网站搜索的用户。

## 范围与取舍

- 采用普通核对说明：不增加权限，不发起测试搜索，不读取 Chrome 的默认搜索配置，不增加存储。
- 不采用自动检测：Chrome 的公开 search API 只有发起查询，不能读取默认引擎。主动测试还需新增 search 权限，且未触发扩展不等于设置不一致。
- 不根据最近用过的组合或 setupDone 推断默认搜索；其他组合可以通过快捷字词主动调用。

## 呈现与操作

1. 默认组合的左右选择框下方显示一段普通 hint：Chrome 的默认搜索需单独设置；更改组合后需更新对应的网站搜索网址，并确认设为默认。末尾提供“查看设置步骤”链接。
2. 说明不依赖临时状态，刷新或重开后仍存在。在本页刚修改组合时，用现有的修改提示替换普通说明，避免重复。原有首次设置档位和改回原组合的逻辑不变。
3. 使用现有字体、颜色和链接样式，不加告警图标、状态标签、弹窗或动画。说明距选择框 8px，与后面的窄窗口设置保持现有间距。
4. 链接复用 revealGuideSteps：左键及键盘激活切到“添加到 Chrome”，展开设置步骤并移动焦点；Ctrl/中键通过真实 href 新开。固定链接 id 支持重渲染后的焦点恢复。
5. “添加到 Chrome”默认触发网址旁的说明明确提醒在 Chrome 添加或更新网站搜索，网址与展示值一致，并设为默认。
6. 原有修改提示与保存提示改为操作指引，去掉“Chrome 仍在用旧网址”的未经检测的状态断言。

## 文案与约束

- zh_CN 为源文案，en、zh_TW、es 同步更新；Chrome 术语沿用 docs/i18n/chrome-terms.md。
- 沿用现有 tNodes 占位符插入链接，不拼接可翻译的句子。
- 不更改 manifest、搜索和分屏行为、权限、storage、默认组合、关键词规则。
- 页面窄宽布局及四语不设行长上限的既有规范不变。

## 验证

运行现有单元测试、B21 / B14 / I18N 设置页验收，并对新说明做一次性浏览器核对：刷新、修改/改回组合、首次设置与已完成状态、链接焦点、四语宽窄屏与深浅色。低风险说明文案不另写重复实现的单元测试。
