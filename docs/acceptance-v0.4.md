# Split Search v0.4 验收清单

扩展 ID 应为 `alngkkgnobglnfbhcplhpaflcgfiajnj`。v0.4 的新功能：把现有搜索补成分屏（工具栏弹窗）、边读边查（选中文字右键）、以图搜图（图片上右键）。设计见 `docs/superpowers/specs/2026-10-25-v0.4-read-and-search-design.md`。

v0.1 的 B/T 表（`docs/acceptance-v0.1.md` 第 3 节）和 v0.3 的表（`docs/acceptance-v0.3.md`）照旧有效，运行方式、显示模式、真实输入的前提、报告与结果分类都以 v0.1 第 1 节为准。本表只列 v0.4 新增和改写的项目。

**T5 的重启期望从 v0.4 起改了**：重启浏览器后 `storage.session` 已清空，恢复出来的本扩展分屏两侧都没有记录，再触发一次时不再就地刷新，而是在旁边新开一对，原来两侧都不动（spec 3.1“兜底”）。e2e 的 T5 重启子项已按此判定。

## 1. 怎么跑

- 日常回归：`npm run e2e -- --auto-only`。默认在不可见的 Xvfb 里跑，无人值守，xauto 步骤（T21、T22、T24 的真实右键与快捷键）照跑。
- 只跑 v0.4 的项目：`npm run e2e -- --auto-only --only B4,B14,B18,B19,T20,T21,T22,T23,T24,I18N`。
- 不授权的模拟 host：`engine-u.localhost`（模拟引擎 U）、`page-u.localhost`（普通文章页，有两段文字、一张 http 图片和一张 `data:` 图片）、`engine-i.localhost`（模拟以图搜图引擎，页面回显收到的图片网址）都不在一次性授权里，已有的测试配置不用重新授权。扩展读不到这些标签的网址，步骤一律从 CDP 读。
- 页面没被导航的证据：步骤给不该被动的标签写一个随机标记（`window` 上的变量），结束时按 CDP 网址和标记核对。网址相同但页面重载过，标记就没了。
- 右键菜单：按文字行定位本扩展的菜单项（倒数第二行，紧挨“检查”），悬停确认高亮后点击，不向菜单发送任何按键。报告里写当次菜单的行数和点的是第几项；对不对以效果判定（分屏是否建成、网址是否正确）。
- 存储基线不加 `lookupEngine`、`imageEngine`、`imageEngines`。用到它们的步骤（B18、T21、T22、T24）自己写，结束时写回步骤前的值。T24 的 (d') 和 T19 一样临时绑 `cycle-right` 快捷键、改 `cycleExclude`，结束时改回。

## 2. B/T 表（注明覆盖方式）

“覆盖”一列的写法同 v0.3：**e2e auto** = 脚本全自动（`--auto-only` 也跑）；**e2e 自动（真实输入）** = xauto 步骤，脚本用真实鼠标或键盘操作并判定，没有真实输入时换成后面写的回退版本；**e2e assist** = 向导请你操作、脚本判定；**e2e judge** = 向导里由你判断（脚本再核对）；**未覆盖** = 本版不测或需要时手测。搜索引擎都用模拟引擎 A ｜ B（`ea`/`eb`，路径型模板的模拟引擎 C `ec`）代替真实引擎，链路相同。查词引擎缺省跟随默认组合的右侧，即模拟引擎 B。

### 预期行为（不是 bug）

- 用弹窗换了右侧之后，下一次右键查词仍按设置页的查词引擎查，会把右侧换回去。菜单标题写的就是设置页里的引擎名。
- `tab` 缺失时（例如在侧边栏里右键）点菜单没有任何反应，只记日志。
- 选区在输入框、文本域或可编辑区域里时，菜单项会出现，但点了不处理：用户正在输入的内容不发出去。
- 补成分屏后，左侧网址仍带着 `_ss`（如果原来带着）。左侧引擎已授权时刷新左侧，页面只显示“重新执行”按钮；没授权时刷新就是普通刷新。
- 本扩展相邻搜索对（窄窗口降级时的一对）的任一侧右键查词，它会成为新分屏的左侧，原来那一对随之失效。
- 浏览器重启或扩展更新后，在恢复出来的本扩展分屏里再触发，会在旁边多开一对，不就地刷新。之后新开的这一对照常复用。
- 窄窗口里右键查词，查询标签在旁边打开并切到前台（与 go.html 和补成分屏的后台标签不同）；再次查词复用它时同样切到前台。
- 菜单显示范围（Chrome 156 实测）：`chrome://` 页面和无痕窗口里不出现；PDF 查看器里出现选区项，边读边查照常可用；`srcdoc`、`about:blank` 的 iframe 里不出现，跨 origin 的 http(s) iframe 里出现；应用店页面没有实测，预期不出现。

### 本版不在 e2e 里测的

- 真点工具栏图标：工具栏图标的位置是浏览器界面的实现细节，xauto 去点它不稳定。“点图标授予 activeTab、弹窗关掉后扩展仍读得到网址”只在实现前做过一次性 spike（S2）；e2e 用 CDP `Extensions.triggerAction`，效果相同。
- Lens、Bing、Yandex 等真实以图搜图引擎：外网和人机验证不稳定，只做人工抽查。
- Service Worker 被回收后冷启动时点菜单：e2e 的调试会话让 SW 一直存活（同 v0.1 第 3 节的说明），靠手测。
