# Split Search

Compare results from two search engines side by side in Chrome’s split view, or look up text and images right next to the page you’re reading.

- Search from the address bar or drag text onto the tab strip to open two engines at once. Add custom engines and set up multiple pairs, each with its own shortcut.
- Right-click selected text or an image to look it up beside the current page.
- Click the toolbar icon on a configured engine’s results page to add a second engine, or switch the right-side engine anytime without retyping.
- Switch the right-side engine automatically by keyword or writing system, such as using YouTube when a search contains “video”.
- Queries go straight to the engines you pick, with no servers, analytics, or ads.

**[Install from the Chrome Web Store](https://chromewebstore.google.com/detail/Split%20Search/ebefmgpipceocigodihbbbhdiagmjdak)**
