# Split Search

A Chrome extension that opens search results side by side in Chrome's split view: one search in two engines, or a lookup next to the page you're reading.

- Search from the address bar, or drag text onto the tab strip, and get two result pages at once. Pick your own engines and set up several pairs.
- Right-click selected text or an image to look it up next to the page you're reading.
- Switch the right side to another engine from the toolbar, without searching again.
- Keyword rules can switch the right-side engine for you, for example to YouTube when your search contains "video".
- What you look up goes only to the engines you pick. No servers, no analytics.
