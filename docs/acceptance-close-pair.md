# 搜索分屏联动关闭验收

设计见 [2026-11-01-close-search-pair-design.md](superpowers/specs/2026-11-01-close-search-pair-design.md)。不增加权限，版本号保持 0.7.0；功能尚未发布。

## 适用范围与边界

- 设置在“搜索组合”中，默认关闭。只联动本扩展记录确认的 search/search 原生分屏，左右均可触发；页面跳转后仍联动。
- page/lookup 右键查询、窄窗口 adjacent、手动分屏和失效记录不联动。明确拆开、移动到其他窗口、关闭设置会撤销许可。
- Chrome 无法完全区分“直接关闭”与“拆开后立即关闭”；后者仍可能联动，尤其后台冷启动时。四种语言的设置说明与 README 均提示这一边界。
- 对侧拒绝离开页面后保持打开，配对记录和关闭许可已经消费，不重复尝试。后台丢失事件、存储失败或锁不可用时保守跳过。
