# Split Search

[English](README.md) | **简体中文** | [繁體中文](README.zh-TW.md) | [Español](README.es.md)

一次搜索，在 Chrome 拆分视图中左右并排打开两个搜索引擎的结果。

![Chrome 拆分视图中，左侧 DuckDuckGo、右侧 Bing 同时显示“rust programming”的搜索结果](assets/readme/hero.png)

## 功能

- 地址栏搜索或把文字拖到标签栏，直接并排打开两个搜索引擎；可添加自定义引擎，也能设多套组合按快捷字词切换
- 网页上选中文字或对图片点右键，保留原网页，在旁边分屏查词或搜图
- 在已配置引擎的搜索结果页点工具栏图标，可在右侧加开第二个引擎；分屏中点图标或按快捷键可随时切换右侧引擎，不用重新输入
- 搜索词含特定关键词或日文、韩文等文字时，自动换用指定右侧引擎（如搜“视频 猫”时右侧换用 YouTube，还能顺手去掉“视频”二字）

## 安装

需要 Chrome 155 或更高版本。

**[从 Chrome 应用商店安装](https://chromewebstore.google.com/detail/Split%20Search/ebefmgpipceocigodihbbbhdiagmjdak)**

手动安装：

1. 在 [Releases](https://github.com/pine2D/split-search/releases/latest) 下载 `split-search-<版本>.zip` 并解压。
2. 打开 `chrome://extensions`，开启右上角“开发者模式”，点“加载未打包的扩展程序”，选择解压后的文件夹。
3. 安装后会自动打开设置页。

更新时直接解压覆盖原文件夹，再点扩展卡片上的“重新加载”。若换了文件夹，Chrome 会当作新扩展处理，原有设置无法继承。

## 快速上手

直接在搜索结果页使用：打开 Google、Bing 等搜索结果页，点工具栏上的 Split Search 再选一个引擎，就能在右侧并排对比，原有默认搜索照常保留；也可在设置页“开始使用”中给左侧引擎授权后点“试搜示例”。

想从地址栏直接分屏，可在 Chrome 添加一条网站搜索：

1. 在设置页“搜索组合”选好左右引擎（如提示未授权，先给左侧引擎授权），切到“添加到 Chrome”复制组合网址，点“打开 Chrome 搜索设置”。
2. 在“网站搜索”旁点“添加”，填写名称与快捷字词（如 `gb`），把网址粘贴到“网址格式”栏，再点“添加”。
3. 在地址栏输入快捷字词，按 Tab 后输入搜索词就能分屏搜索。若想直接输词或把文字拖到标签栏也打开拆分视图，在该条目 ⋮ 菜单中选“设为默认选项”（作为默认搜索引擎时，地址栏不显示搜索联想）。

## 补充说明

- 可在“搜索组合”中开启“关闭一侧时，同时关闭另一侧”（默认关闭），只对本次会话中本扩展打开的搜索分屏有效，点进其他链接后依然有效；右键查询与窄窗口相邻标签页不会一起关闭。取消拆分视图后立即关标签页时，另一侧偶尔仍会被一起关闭。
- 窗口较窄（宽度不足 960 像素）时默认改用相邻标签页：搜索时右侧结果在后台打开，右键查词或搜图则直接切到查询标签页。
- 在无痕式窗口、未启用本扩展的其他设备或未给左侧引擎授权时，组合网址会直接打开普通的左侧引擎结果页，不会报错。

## 隐私

搜索词、所选文字和图片网址只发往你选择的搜索引擎，绝不发给开发者或其他第三方。本扩展没有服务器，不含统计与广告：建立拆分视图时只在本地读取搜索网址和当前标签页网址，用完不保存；只有你点击本扩展的右键菜单时，才会读取选中的文字或图片网址；当前分屏的查询记录只暂存在浏览器内存中，关闭浏览器即清空。详见[隐私政策](https://pine2d.github.io/split-search/privacy.zh-CN.html)。
