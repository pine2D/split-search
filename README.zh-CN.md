# Split Search

[English](README.md) | **简体中文** | [繁體中文](README.zh-TW.md) | [Español](README.es.md)

在地址栏搜索，或把文字拖到标签栏，Split Search 会用 Chrome 拆分视图左右打开两个搜索引擎的结果，方便对比。

![Chrome 拆分视图中，左侧 DuckDuckGo、右侧 Bing 同时显示“rust programming”的搜索结果](assets/readme/hero.png)

## 功能

- 地址栏搜索、拖拽文字到标签栏、右键“使用X搜索‘…’”都能用
- 已经打开某个引擎的结果页时，点工具栏按钮选另一个引擎，就能和当前页组成拆分视图
- 在网页上选中文字后右键，可以在拆分视图里查这段文字，当前网页留在左边
- 在图片上右键，可以用 Google Lens 等引擎以图搜图，结果在当前网页旁边打开
- 预置 Google、Bing、DuckDuckGo、Perplexity、Kagi，也可以添加其他搜索引擎
- 引擎库收录翻译、百科、视频、地图等适合放在右侧的网站，也有 AI 助手，可以直接添加
- 可以设多组引擎，各用一个快捷字词，例如输入“gb 关键词”对比 Google 和 Bing
- 点工具栏按钮，可以把右侧换成别的引擎，不用重新搜索
- 也可以按快捷键把右侧换成下一个引擎。快捷键默认未设置，在 `chrome://extensions/shortcuts` 设置
- 窗口较窄时，右侧改在旁边的后台标签页打开，这项可以在设置页关闭
- 两侧都是普通标签页，登录状态和网站设置照常

## 安装

需要 Chrome 155 或更高版本。

1. 下载本仓库，打开 `chrome://extensions`，开启右上角的“开发者模式”。
2. 点“加载未打包的扩展程序”，选择仓库里的 `src` 文件夹。
3. 安装后会自动打开设置页。

## 设置

第一次打开设置页时，顶部的“开始使用”卡会一步步带你完成下面的设置，做完还能当场试一下。

1. **授权**：在设置页给要用的搜索引擎点“授权”。
2. **复制网址**：在“默认组合”里选好左右两个引擎，再从“开始使用”卡或“添加到 Chrome”复制生成的网址。
3. **添加并设为默认**：在地址栏打开 `chrome://settings/searchEngines`，在“网站搜索”旁点“添加”。名称随意，快捷字词自定（例如 `gb`），“网址格式”一栏粘贴刚复制的网址，再点“添加”。然后在这一条右侧的 ⋮ 菜单里选“设为默认选项”。

只用快捷字词的话，不必设为默认：在地址栏输入“快捷字词 + 空格 + 关键词”即可。这时拖拽和 Chrome 自带的右键搜索仍用原来的默认搜索引擎。

## 须知

- 在无痕式窗口、其他设备上，或扩展没有生效时，就是一次普通搜索。
- 设为默认后，地址栏不再显示搜索联想。
- 只有带公开网址的图片才能以图搜图，要登录才能看的图片，引擎多半拿不到。

## 隐私

扩展不把数据发给开发者或其他第三方，你要查的内容只发给你选的引擎。扩展没有服务器，不含统计和广告。只有你选了本扩展的右键菜单项时，它才读取选中的文字或那张图片的网址，不读取页面网址和页面上的其他内容。查询的内容和两侧引擎只暂存在浏览器内存里，供弹窗和快捷键换引擎，关闭浏览器即清除。详见[隐私政策](https://pine2d.github.io/split-search/privacy.zh-CN.html)。
